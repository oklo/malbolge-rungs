# Attempt reports

One file per serious attempt at a board rung, solved or not:

```
docs/attempts/YYYY-MM-DD-<solver>-<rung>.md
```

Include the method, the search budget consumed (configurations, nodes, wall
time, tokens where known), per-case native results, and what failed. Failed
attempts are as welcome as solves — a record containing only wins overstates
every method it lists, and the negative results here have repeatedly been the
starting point for the next construction.

For solves, the report complements the leaderboard record: the record carries
the claim and attribution, the report carries the method. Reference any search
code checked in under `research/`.
